## 这是个什么游戏

模拟骑行的外壳，人生算账的内核。你手里只有四样本钱——**命、时间、钱、心力**，骑行的每一公里都在花它们：

- **14 个人生站牌**：18 岁的安全带、24 岁的奶茶店、30 岁的月供……骑到就触发剧情，你做选择，故事给你后果，然后翻开书中那一页原文
- **摔跤才有奖励**：撞石头、翻车、掉断崖，会弹出一条还没悟过的道理——优先落在你正骑着的人生阶段
- **路上的行囊**：8 种小物件每件藏一条道理——夜灯回体力、伞挡一次摔跤（**挡不住断崖**）、指南针带来顺风、同行的鸟守住连击
- **登山赛车式驾驶**：6 段各有脾气的地形（海边 / 丘陵 / 梯田 / 搓板 / 沙丘 / 断崖）、顺风与顶风、岔路近道与大道、后空翻特技与连击倍率
- **会变的天**：晴 / 夜 / 雨 / 雨夜按里程自动轮换，雨夜路滑
- **本程目标**：2 个滚动小目标（跳 10 次、不摔连骑 1000 米……），达成奖鱼
- **车库改装**：接鱼攒钱，升级牙盘、心肺、避震、车架，永久生效
- **六十岁的结语**：无论骑成什么样，结算都落在一条道理上；选不同出身，开不同的车

## 怎么玩（一句话版）

竖屏单手就够：**右下角大圆键「蹬」（按住前进），左下角「跳」**。
倒木和断崖按「跳」，腾空时再按一次可补跳；同一处连着栽两次会自动放行，绝不卡关。

## 特点

- **单文件**：整个游戏就是一个 `index.html`，所有样式/脚本/图标全部内联，双击离线可玩
- **零依赖**：无框架、无构建依赖、无外部资源，SVG 手绘 + 原生 JS
- **手机优先**：竖屏驾驶舱布局、拇指大按钮、刘海安全区、老 iOS（iOS 15.4 以下）兼容、56~60 帧
- **卡顿自愈**：内置 FPS 看门狗，低端机自动降档（减粒子/降刷新），流畅后自动升回
- **防卡死**：土狼时间、跳跃缓冲、二段跳、同一障碍两栽放行、5 秒脱困兜底

## 仓库结构

```
index.html      主游戏（单文件，部署即用）
corridor.html   回廊探索版（另一个玩法，同一本书）
robots.txt
push_api.py     通过 GitHub API 提交的发布脚本（git 被墙时的备用通道）
```

源码工程（拆分的多文件版本、构建脚本、自动化测试）在本地维护：

```bash
python build_bt.py        # 内联打包 → 单文件 + 宝塔部署 zip
python qa/_rules.py       # 机制回归（出身差异/掉崖/跳台/倒木/绕回）
python qa/_props.py       # 道具与结局结语 17 项
python qa/_goals.py       # 目标系统与自动天气 12 项
python qa/_fit.py         # 手机竖屏布局量测
python qa/_soak.py        # 45 秒长跑（摔倒统计/报错）
```

测试基于纯 Python 标准库 + Chrome DevTools Protocol，无第三方依赖。
